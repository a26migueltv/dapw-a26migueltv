## Exercicio 1: Configuración da infraestrutura

### 1.1 Descarga da imaxe de Debian 12

Descargouse a box de Debian 12 seleccionando VirtualBox como provedor:

```bash
vagrant box add debian/bookworm64
```

### 1.2 Modificación do Vagrantfile

Na lista `maquinas` do `Vagrantfile` substituíuse `iniciais` polas miñas iniciais (**mtv**) en cada un dos dicionarios.

**Captura 1 – Ficheiro de configuración de Vagrant**

![image-20261006115549535](/home/sanclemente.local/a26migueltv/.config/Typora/typora-user-images/image-20261006115549535.png)

### 1.3 Arranque das máquinas

```bash
vagrant up
```

Tras uns minutos, as máquinas aparecen en execución en VirtualBox.

### 1.4 Conexión por SSH dende Visual Studio Code

1. Instalouse a extensión **Remote - SSH** en VSC.
2. Con `F1` → *Remote-SSH: Add New SSH Host* engadiuse o host co comando:

```bash
ssh dadmin@192.168.56.101
```

1. Gardouse no ficheiro de configuración SSH do meu usuario.
2. Con `F1` → *Remote-SSH: Connect to Host* conectouse á IP `192.168.56.101` co contrasinal do usuario `dadmin`.
3. Abriuse un novo terminal, que se inicia na máquina virtual.
